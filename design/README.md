# Logo projektu

Vlastní vektorový motiv geometricky větveného zeleného stromu s listy a kořeny, navazující na texturu pozadí.

- logo-symbol.svg: samostatný symbol
- logo-horizontal.svg: symbol a název Kořeny osobností

Záhlaví a patička náhledu používají stejný symbol. Slovo „oficiální“ označuje zamýšlené použití pro projekt; tyto soubory nepředstavují schválení spoluautory ani souhlas k produkční publikaci. Text v horizontálním SVG zůstává editovatelný.
